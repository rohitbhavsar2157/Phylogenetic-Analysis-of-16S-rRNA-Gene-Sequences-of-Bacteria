# Phylogenetic-Analysis-of-16S-rRNA-Gene-Sequences-of-Bacteria
To construct and interpret a phylogenetic tree using 16S rRNA sequences of  selected organisms and understand their evolutionary relationships.
16S rRNA is widely used in phylogenetic analysis because it is universally present in bacteria, contains both conserved and variable regions, evolves slowly, and serves as a reliable molecular marker for determining evolutionary relationships and identifying bacterial species.
